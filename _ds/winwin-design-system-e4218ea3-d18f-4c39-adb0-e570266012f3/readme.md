# Winwin Design System

Winwin (وين وين — tagline "ملعب كل الرياضات", "the stadium of all sports") is an Arabic-first sports app: live scores, match details, fixtures, news, videos and favourite teams/players/championships. The Figma file covers one product surface — the **iOS mobile app (390 × 844, RTL Arabic)** — plus a component kit built on an Untitled-UI-style base that was re-tinted to the Winwin red.

## Sources
- Figma file: **"Winwin DS.fig"** (uploaded; mounted read-only). Pages: FOUNDATIONS, Icons (22 frames), Misc-Icons, Flags, Logos, Buttons, Inputs, Tags, Checkboxes, Badge, Tab, Content-divider, Accordion, Progress-bar, Application-navigation (78 frames — all app screens), Mobile-Elements, Draft.
- No codebase, website or deck was provided.

- `tokens/fig-tokens.css` — all 611 Figma variables (5 collections; light + dark modes as `:root[data-theme="dark"]`). Unitless FLOATs — use `calc(var(--x) * 1px)`.
- `tokens/semantic.css` — px-resolved aliases: `--ww-red`, `--text-primary`, `--surface-card`, `--space-*`, `--r-*`, `--shadow-*`, `--font-ui`.
- `tokens/fonts.css` — Google Fonts import. `tokens/fig-typography.css` — empty (file defines no text styles).
- `components/` — 157 materialized React components (flat dir) + `*.card.html` specimen cards + `fig-assets.css` / `assets/` bitmaps.
- `assets/icons/` — `Icon` (1268 line + sport glyphs), `assets/flags/` — `Flag` (262 circular flags), `assets/country-icons/` — `CountryIcon` (132 ISO-code icons), `assets/logo.svg`, `assets/logo-on-dark.svg`.
- `guidelines/` — foundation cards (colors, type, spacing, radii, shadows, brand).
- `ui_kits/winwin-app/` — click-through recreation of the app (Splash, Login, Home, Matches, Match details, News, News details, More).
- `SKILL.md` — agent-skill entry.

## Content fundamentals
- **Language:** Arabic (MSA, sports-journalism register), RTL. English appears only for league names in some rows ("Premier League", "England") and in the English keyboard/EN input variants.
- **Voice:** direct, newsy, energetic. Section titles are short noun phrases: "مباشر الآن" (Live now), "مباريات اليوم" (Today's matches), "فيديوهات" (Videos), "آخر الأخبار" (Latest news), "مفضلتي" (My favourites). "المزيد" (More) is the universal see-all link.
- **Headlines** use a label + pipe: "خاص | رئيس أتلتيكو مدريد يحسم الجدل بشأن مستقبل سيميوني". Bylines: author • date ("إسماعيل محمود • 8 مارس 2026").
- **Address:** second person, warm: "أهلا بعودتك .." (Welcome back ..), "سجّل دخولك للاستمتاع بكل أخبار ومباريات كرة القدم".
- **Numbers:** Western digits for scores, minutes and times ("2 - 1", "67'", "18:00").
- **No emoji.** Status is conveyed with the red live dot, tags and icons.

## Visual foundations
- **Color:** one brand red `#DB2F21` (`--primary-500-primary`) on white, with zinc neutrals (`--gray-gray-*`, ink `#09090B`). Red is reserved for the logo mark, active nav tab, "المزيد" links, live score/minute, primary buttons and the floating CTA pill. Gold accent ramp (`--accent-*`) and team-palette tokens exist but are rare. Semantic success/warning/error/info ramps come from the kit. Dark-mode values exist for the kit tokens.
- **Type:** Readex Pro is the app face (Arabic + Latin); titles 18–20 Bold/SemiBold, body 14 Regular, meta 10–12. Cairo SemiBold for buttons/tabs, IBM Plex Sans Arabic in nav labels, Inter Medium 14 across the generic kit components. Scale tokens: 10/12/14/16/18/20/24/30/36/48/60/72.
- **Signature motif:** a pale gray **slanted slash** behind section titles (HeaderContainer) and a diagonal-stripe texture on the splash — echoing the logo's italic "W" strokes. The Arabic tagline sits in a red parallelogram.
- **Spacing:** 20px screen gutters, 20px between sections, 16px heading-to-content, 8px between list rows, 12–16px card padding. Scale 2/4/6/8/12/16/20/24/32/40/48/64/80/96/128/160.
- **Radii:** cards 12px, list rows 12px, pills/tags full, inputs 8px, avatars circle. Tokens 2–24 + 9999.
- **Cards:** white or `--gray-gray-50` fill, 1px `--gray-gray-200` border, no shadow in the app. Live-match cards add a red-tinted border and a faint red corner wash (`linear-gradient(166deg, transparent 70%, rgba(228,125,115,.1))`).
- **Imagery:** full-bleed editorial football photography (warm stadium light, real players), always under a black bottom-up protection gradient (0.9 → 0.3 → 0) with white Arabic text. Video tiles use a centered translucent play button and a blurred bottom band. Team crests shown on white circles.
- **Shadows:** kit shadow-xs/sm/lg (rgba(10,13,18,…)) used for dropdowns/tooltips; app surfaces are flat.
- **Transparency/blur:** white 10–30% chips on photos (tags, play buttons); blur behind video captions.
- **Motion:** only the pulsing red live dot (PulseAnimatedRed, 4 frames) and heart-favourite states are defined; assume short fades, no bounce.
- **States:** buttons darken on hover (primary-600); tabs switch to red fill/underline; bottom-nav active item turns red with a red outline box; disabled = gray-300 text.
- **Layout:** fixed iOS status bar, top bar (logo right, live pill + bell + search left), fixed 5-item bottom nav, floating red "مباريات اليوم" pill above it. Horizontal carousels bleed off the leading edge.

## Iconography
- Line icon set (Untitled-UI style, 1.5–2px stroke, 24px grid, currentColor) — 1268 glyphs in `assets/icons/icon-data.js`, render with `<Icon name="Home012" size={24}/>`. Names are PascalCase from Figma with numeric de-dup suffixes (see `Icon.d.ts`).
- Custom sport glyphs (Stadium, Gool, Race, FootballShoe, Sport/*) in the same set.
- 262 circular country flags (`Flag`) and 132 square country icons (`CountryIcon`, ISO codes) for leagues/nationalities.
- Social icons and file-type icons are components (`SocialIcon`, `FileTypeIcon`).
- No emoji, no icon font, no unicode-as-icon.

## Logo
The file ships the real logo (red dot + W mark, black "WINWIN" wordmark) as vectors — `assets/logo.svg`, `assets/logo-on-dark.svg`, and the `FullLogo` component (variant2 adds the red tagline strip).

## Fonts — substitutions
Readex Pro, Cairo, IBM Plex Sans Arabic, Tajawal, Rubik, Inter, Roboto, Poppins load from Google Fonts. **Lusail+**, **Bahij TheSansArabic** and **Estedad** (proprietary) and **SF Pro** (Apple) are not shipped — they fall back to the stack. Please supply font files if exact rendering matters.

## Intentional additions
- `Icon`, `Flag`, `CountryIcon` — wrappers over the icon/flag glyph sets.
- `tokens/semantic.css` aliases.

## Known gaps
- The compiler counts ~403 "families" because it includes standalone symbols: ~1268 icon glyphs, 262 flags and 132 country icons (all shipped via `Icon` / `Flag` / `CountryIcon` icon-data rather than one component each) and keyboard key-layout sub-symbols (shipped as KeysLayout* and inside the IOS*Keyboard components). All 92 component sets listed in the file metadata are built.
- Several component families share names in Figma (two "Buttons/Button", three "Badge", three "Tag", two "Accordion", two "Navigation Bar", two "Step icon base", two "Progress bar"). Suffixed components (ButtonsButton2, Badge3, Tag2/Tag3, NavigationBar2, StepIconBase2, ProgressBar2) cover them; the 105-variant "Badge" duplicate is identical in axes to TagColored and the second Accordion was not found as a separate set.
- Frame-named families (Frame1321314636 etc.) keep their Figma layer names.

## Intentionally skipped families (and why)
The compiler's 403-family count includes every standalone symbol in the file. All 92 variant component sets are built; the remaining standalone symbols are deliberately not built as one component each:
- **Icon glyphs (~1,268 symbols, Icons page)** — shipped as data in `assets/icons/icon-data.js`, rendered via `Icon name="…"`. One component per glyph would add ~1,268 exports for no API benefit.
- **Country flags `001-paraguay` … `262-italy` (262 symbols, Flags page)** — shipped via `Flag name="…"`.
- **Country icons `AD` … `ZW` (132 symbols)** — shipped via `CountryIcon name="…"`.
- **`.Keys Layout / …` (12 symbols: Alphabetic Arabic/English × Default / No home indicator × light/dark, Numeric Arabic/English × light/dark)** — private sub-layers (leading `.` = hidden in Figma) of the keyboard sets. They are built as `KeysLayoutAlphabeticArabicDefault`, `…Default2` (dark), `…No` (no home indicator), `…No2` (no home indicator, dark), and the English/Numeric equivalents, and are consumed by `IOSAlphbeticKeyboardArabic`, `IOSAlphbeticKeyboardEnglish`, `IOSNumericKeyboard` via their `darkMode` / `homeIndicator` props.
- **`_Scroll bar (control fill with bottom padding)`** — private sub-part, built as `ScrollBarControlFillWith` and used inside `InputDropdown`.
- **`.Label`**, **placeholder** icon slots, club crests and flag-pack symbols used only inside cards — built as `Label`, `Placeholder*`, `ClubLiverpool`, `ClubAstonvilla`, `FlagPackEngland`, etc.

The `Estedad` family referenced by `--font-family-font-family` has no font file in the source; the token is kept as-is and renders with the fallback stack until the file is uploaded.
